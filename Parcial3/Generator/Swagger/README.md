# API de Gestión de Usuarios 🚀

**Documentación técnica para desarrolladores**  

## 📌 Descripción  
API RESTful construida con Node.js y Express para gestionar usuarios. Documentada con Swagger (OpenAPI 3.0) para una integración sencilla y pruebas interactivas.  

## 🔍 Endpoints  

| Método | Ruta         | Descripción                     |
|--------|--------------|---------------------------------|
| GET    | `/usuario`   | Obtener todos los usuarios      |
| POST   | `/usuario`   | Crear un nuevo usuario          |
| DELETE | `/usuario`   | Eliminar un usuario por ID      |
