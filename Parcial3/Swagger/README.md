# README

## Proyecto: ApiRestGuillermoDelBosque

Este proyecto es una API REST desarrollada como parte del Parcial 2. A continuación, se describen los detalles básicos del proyecto.

## Requisitos

- Node.js
- npm o yarn

## Instalación

1. Clona este repositorio:
    ```bash
    git clone <url-del-repositorio>
    ```
2. Instala las dependencias:
    ```bash
    npm install
    ```

## Uso

1. Inicia el servidor:
    ```bash
    npm start
    ```
2. Accede a la API en `http://localhost:<puerto>`.

## Documentación

La documentación del proyecto está generada con JSDoc y se encuentra en la carpeta `jsdoc`.
